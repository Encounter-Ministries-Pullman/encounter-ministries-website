# Encounter Ministres Pullman Church Website

## Description

This repository contains the codebase for the website of Encounter Ministries Church in  
Pullman, WA. The purpose of this project is to provide an extensible, easily modifiable,  
and flexible website through modern technologies. Even church staff that do not have  
significant experience with software engineering principles or other coding-related  
skills will ideally be able to update relevant portions of this website at-will through  
easy-to-use user interfaces.
